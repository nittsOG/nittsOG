# Profile README Design System

## Theme
Cyber Security / Security Engineering / Security Research

## Palette
- Background: #05080B
- Primary: #00FF9C
- Secondary: #00D9FF
- Text: #F1F7F8
- Muted: #A9C4C8
- Grid: #0C3035

## Rules
1. Security is the primary identity.
2. Projects provide evidence for the identity.
3. Do not use fake skill percentages.
4. Keep animation minimal.
5. Prefer accessible Markdown/HTML text over image-only content.
6. Keep project claims limited to work that can be publicly supported.

## v0.5 Repository Audit

- `nittsOG` currently exposes 7 public repositories; the profile prominently features `idecop-ics`, `promptscribe`, `KAVACH`, and `smis`.
- `idecop-ics` is treated as the primary flagship security/ICS project.
- `PromptScribe` is treated as an active engineering project.
- `KAVACH` is explicitly marked as a fork and is not used as evidence of original authorship.
- Current/private security work remains intentionally generic; no employer/project-sensitive details are added.
- The profile avoids fabricated metrics, skill percentages, or ownership claims unsupported by the public repositories.
